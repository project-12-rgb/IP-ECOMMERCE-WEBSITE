PROJECT OVERVIEW

About the Project

E-Mart Global Sales Analysis is a data-analysis project designed to study sales and profit information of a retail business using Python, Pandas, Matplotlib and SQL.

🎯

Objective

Analyse sales, profit, products, categories and regions.

💻

Technologies

Python, Pandas, Matplotlib, SQL, HTML, CSS and JavaScript.

📈

Purpose

Convert sales information into useful business insights.
